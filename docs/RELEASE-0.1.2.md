# 0.1.2 开源预发布 · 2026-10-14

这是源码公开和独立发行签名的首次预发布，不是全部功能已验收的正式产品。

## 下载选择

- `debate-training-arm64-release.apk`：ARM64 安卓手机与平板。
- `debate-training-x86_64-release.apk`：x86_64 模拟器，不用于通常的 ARM64 手机。
- `third-party-notices.zip`：依赖许可、来源清单及部分上游源码。
- `SHA256SUMS.txt`：下载文件校验值。

应用标识 `com.debate.training.android.opensource`，版本名 0.1.2、版本号 1002，min SDK 26、target SDK 36。可与旧测试版并存，不会自动复制旧数据；不要为安装本版本而卸载旧版。

## 实际检查范围

- 公开副本：30 个前端测试文件、166 项测试通过；typecheck、lint、format、production build 通过。
- 独立安卓工程：29 项浏览器移动/平板布局回归通过。它们不是原生平板或完整比赛验收。
- Rust：256 项常规测试通过，11 项被忽略的真实模型测试未运行；重复三次默认并行运行均通过。fmt 与 clippy 检查通过。
- 发布配置：4 项回归检查通过，包括应用标识隔离、签名配置、调试开关和依赖输出目录隔离。
- `npm audit`：本次更新后报告 0 项已知漏洞；这不等于完整安全审计。
- Android 35 AOSP x86_64 模拟器：安装及冷启动通过，欢迎页不自动跳转，手动进入工作台和模型设置可用。合成密钥保存、重启读取、清除均通过，未点击“测试连接”。`run-as` 被系统拒绝，旧测试版仍与新版本并存。
- ARM64 包只验证编译、签名和静态属性，本次未在实体手机安装或跑真实付费比赛。

首次 Rust 并行测试曾出现一次日志捕获断言失败；单项、串行和后续三次并行运行通过，尚未确认偶发原因，未删除或放宽断言。手工 UI 复测曾因未等待页面切换而误报重启读密钥失败，改用状态等待的验收脚本后完整通过。

## 构建修复与已知限制

Gradle 官方下载曾发生 TLS 中断和截断 ZIP；使用官方大小与 SHA-256 校验完整下载，未关闭证书验证。个别 Maven 依赖使用官方 HTTPS 下载和官方摘要核对后恢复缓存。ARM64/x86_64 的 Tauri 依赖输出曾共用目录造成 JAR 文件锁冲突，已改为每个临时项目独立输出；ARM64 最终构建验证了隔离修复。x86_64 包在隔离修改前已完成构建，其应用代码与最终公开副本一致。

SDK XML 版本、Java 8 目标和 Gradle API 弃用警告仍存在，未静默隐藏。GitHub Actions 尚未启用，CI 模板位于 `docs/ci-checks.example.yml`，不声称云端 CI 已通过。

完整后台任务、杀进程恢复、原生分享、系统返回键、国产输入法全覆盖、Android 8.0 与真实平板/16 KB 设备仍需继续验收。未启用应用内人民币费用硬上限；真实模型使用会消耗用户自己的 API 余额。详见 [README](../README.md)、[隐私说明](PRIVACY.md)及[安全说明](../SECURITY.md)。
