# 隐私与模型请求

本机账号是应用内数据分组，不是云端注册账户。账号、赛程、比赛发言、输入编辑统计及报告存储在应用私有目录中的 SQLite 数据库；数据库目前不做额外的整库加密。Android 清单关闭系统应用备份。

用户 API 密钥由原生桥接使用 Android Keystore 的 AES-GCM 密钥加密，密文保存在应用私有 SharedPreferences 中。应用需要请求模型时，原生后端在内存中解密并发送授权头。前端不提供读取明文密钥的接口。清除密钥会删除密文及对应 Keystore 条目。

使用赛制识别、读题、AI 发言、AI 评分等模型功能时，相关辩题、赛制、参考材料、策略和公开比赛上下文会发送到配置的模型服务。默认地址是 `https://api.deepseek.com`；修改服务地址意味着数据会发送到该地址，请自行确认服务可信。模型请求可能产生费用，供应商的数据处理规则由其政策约束。不要输入身份证、账号密码或其他无需用于辩论的敏感信息。

当前工程未集成第三方广告、统计或自动崩溃上传 SDK。诊断日志有密钥脱敏，但报告和用户手工导出的发言可能包含个人内容。提交 Issue、日志或截图前请自行删去 API 密钥及个人信息；不要上传数据库。

开源版与旧 debug 版的应用标识和数据目录独立。卸载会删除该版本本地数据，签名或包名变化不会自动迁移记录。

密钥加密不能抵御已取得 root 权限、运行时注入或完整控制设备的攻击者。不开源签名私钥，不能被理解为应用代码保密或所有用户数据都不会联网。
